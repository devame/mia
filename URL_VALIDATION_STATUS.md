- **Lesson**: Read the actual page content, follow the breadcrumbs

## URL Patterns Discovered

### Year-Based Patterns
- NSE India: `/holidays-for-the-calendar-year-{year}`
- ASX: `/T24-trading-calendar{year}.pdf`
- TAIFEX: `/TAIFEX Holiday Schedule {year}.pdf`
- JSE: `/JSE Market Notice ... Markets Calendar {year}.pdf`

### Common Path Structures
- `/trading/calendar` or `/trading-calendar`
- `/holiday` or `/holidays`
- `/market-calendar` or `/trading-hours-calendar`
- `/derivatives/trading-calendar` (for exchanges with multiple markets)

### English Language Patterns
- `/en/`, `/eng/`, `/english/`
- `/enportal/`, `/en-gb/`, `/en_us/`

## Methodology Used

1. **Read Actual Page Content**: Not just search results, but actual page text
2. **Follow Breadcrumbs**: Links mentioned on pages (e.g., SGX→MOM)
3. **Check Sitemaps**: Looked for /sitemap, /calendar, /trading sections
4. **Try Language Patterns**: Tested /en/, /eng/, /english/ variations
5. **Check Announcements**: Many exchanges publish holidays as announcements
6. **Use Site Search**: When available, searched for "holiday", "calendar", "trading hours"
7. **Verify Mobile Sites**: Some exchanges have separate mobile sites (DCE)
8. **Check Data Portals**: Government and corporate data portals (SGX→data.gov.sg, TASE Data Hub)
9. **Direct PDF Search**: Search for PDF calendars when HTML pages unclear
