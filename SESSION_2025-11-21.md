## Technical Challenges Identified

### JavaScript-Rendered Content
**Affected**: XKRX, XNZE, XMCE, MISX

Modern exchange websites increasingly use JavaScript frameworks to dynamically render content. BeautifulSoup can only parse static HTML, making these sites inaccessible without browser automation (Selenium/Playwright).

**Solutions**:
- Implement browser automation (future enhancement)
- Find PDF/Excel calendar downloads
- Discover API endpoints

### Date Format Variations
**Issue**: BSE India uses inconsistent comma spacing in dates
- "February 26,2025" (no space after comma)
- "March 14, 2025" (space after comma)

**Solution**: Implemented regex normalization to standardize format before parsing

### Duplicate Handling
**Issue**: Database UNIQUE constraint on (iso_code, holiday_date) requires deduplication by date, not by date+name

**Solution**: Changed deduplication from `seen_holidays` (date+name) to `seen_dates` (date only)
